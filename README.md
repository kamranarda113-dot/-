# 简易信号源与示波器系统

## 📋 项目简介

本项目实现了一套**简易信号源与示波器系统**，由三部分组成：

| 部分 | 说明 |
|------|------|
| **上位机软件** | PC 端图形界面程序，实现虚拟示波器显示与控制面板，通过串口与下位机通信 |
| **下位机单片机模拟器** | 运行在 PC 端的单片机模拟程序，用于在没有实际硬件时进行联调测试 |
| **单片机程序** | 运行在目标开发板上的嵌入式程序，实现信号采集（ADC）和信号生成（DAC/PWM） |

系统功能：
- **信号源模式**：生成正弦波、方波、三角波、锯齿波等基础波形，频率和幅值可调
- **示波器模式**：实时采集外部信号并在上位机界面上绘制波形，支持时基和电压档位调节
- 上位机与下位机之间通过 **串口（UART）** 进行数据交互

## 🚀 使用方法

### 1. 环境准备

**上位机运行环境：**
```bash
# 示例（Python 环境）
pip install -r requirements.txt
# 或
pip install pyserial pyqt5 matplotlib
```

**单片机程序烧录：**
1. 使用 [Keil / Arduino IDE / 其他] 打开 `mcu_firmware/` 目录下的工程
2. 编译并下载到开发板
3. 使用 USB 转串口线连接开发板与 PC

### 2. 启动步骤

#### 方式一：使用实际硬件

1. 将开发板通过 USB 连接至 PC，确认串口号（如 `COM3`）
2. 运行上位机程序：
   ```bash
   cd upper_computer
   python main.py
   # 或
   ./main.exe
   ```
3. 在上位机界面选择正确的串口号和波特率，点击 **"连接"**
4. 连接成功后，即可使用信号源或示波器功能

#### 方式二：使用模拟器联调（无需硬件）

1. 先启动下位机模拟器：
   ```bash
   cd mcu_simulator
   python main.py
   ```
2. 模拟器会创建虚拟串口（需安装虚拟串口软件，如 `com0com`），或使用 socket 通信
3. 再启动上位机程序，选择对应的虚拟串口号连接即可

### 3. 操作说明

#### 信号源模式
| 参数 | 说明 | 范围 |
|------|------|------|
| 波形类型 | 正弦波 / 方波 / 三角波 / 锯齿波 | — |
| 频率 | 输出信号频率 | [如 1Hz ~ 10kHz] |
| 幅值 | 输出信号幅值（峰峰值） | [如 0V ~ 3.3V] |
| 偏置 | 直流偏置电压 | [如 0V ~ 1.65V] |

#### 示波器模式
| 参数 | 说明 | 范围 |
|------|------|------|
| 时基 | 水平扫描速度 | [如 1ms/div ~ 1s/div] |
| 电压档位 | 垂直灵敏度 | [如 0.5V/div ~ 5V/div] |
| 触发模式 | 自动 / 正常 / 单次 | — |
| 触发边沿 | 上升沿 / 下降沿 | — |

## ⚠️ 常见问题

<details>
<summary><b>Q1: 串口连接失败？</b></summary>

- 确认串口号是否正确（Windows 设备管理器中查看）
- 确认波特率设置为 `115200`
- 确认开发板已正确上电，USB 线支持数据传输
- 检查是否有其他程序占用了该串口
</details>

<details>
<summary><b>Q2: 示波器波形不刷新或卡顿？</b></summary>

- 降低采样率或减少界面刷新频率
- 检查串口数据是否完整，尝试降低波特率
- 确认上位机缓冲区没有积压数据
</details>

<details>
<summary><b>Q3: 信号源输出波形失真？</b></summary>

- 如果使用 PWM + RC 滤波方式，检查滤波电容值是否合适
- 确认 DAC 输出范围与设定值匹配
- 检查输出的负载阻抗是否在驱动能力范围内
</details>
